# Security

Report a vulnerability privately, through GitHub's
[private vulnerability reporting](https://github.com/vvhg1/axiomation/security/advisories/new),
not in a public issue. Say what an attacker can do, and how to reproduce
it.

You get an answer within a week. A fix ships in a release, named in
`CHANGELOG.md`; the advisory is published with it.

Only the latest release receives fixes.
